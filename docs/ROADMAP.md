# Roadmap

Отмечаем `[x]` в том же коммите, где фича сделана.

## Неделя 1 — ядро (текущая)

- [x] Rojo-проект, CI (selene, stylua, rojo build)
- [x] Арена из кода (плитки 10×10 + трибуны)
- [x] Цикл раунда, ускорение, серия сервера
- [x] Цели: survive, reach_zone, freeze
- [x] Угрозы: lava (со столбами), falling (шары с подписью слова), shrink
- [x] Ловушка «без ИИ говорит» (прыжок)
- [x] ИИ-ведущий: Text Generation API → JSON → валидация → резерв
- [x] Голос ведущего (TTS) на клиенте
- [x] Слово победителя: ввод, проверка, фильтр Roblox
- [x] Имена бета-API сверены с API-дампом Roblox: `TextGenerator.GenerateTextAsync(request)`, `AudioTextToSpeech` (VoiceId — строка). Починен голос: у TTS нет `Stop()`, из-за этого ведущий молчал
- [x] **Проверено в Studio** живьём: ИИ отвечает (`ai=true`). Починено: кириллический `UserPrompt` → HTTP 400 (теперь английская обёртка), Seed=0 давал один и тот же раунд (теперь кубики бросает сервер, ИИ пишет фразу), случайные 400 — 3 попытки с паузой
- [x] Голос: Roblox TTS **не умеет русский**, поэтому текст на экране русский, а голос английский. ИИ пишет `voice` (англ. версия фразы), у резерва/ловушек/итогов готовые английские фразы (`Config.FallbackVoice`, `Config.TrapLines`). Проверено в Studio: синтезируется и играет. Повторный «ИИ говорит» из ответа ИИ срезается
- [ ] Тест на друзьях: смеётся ли кто-то в первые 3 минуты

## Неделя 2

- [x] 3D-объект из слова (GenerationService) + кэш в памяти сервера; falling и chaser берут модель, если готова
- [x] Кэш слов: 30 (теперь 40) слов запечены в ассеты (`WordBank.luau`, `tools/bake`), грузятся при старте сервера — модель готова сразу. DataStore не нужен: модель с сервера не сохранить, ассет загружается только из Studio
- [x] Банк — 500 слов: 460 новых запечены пакетами по 20 слов в один ассет (23 загрузки вместо 460), `{ pack, part }` в `WordBank`. Проверено в Studio: все 500 грузятся при старте, у всех текстура
- [x] Формы слова: «коты», «котиков», «драконы», «пиццу», «золотые рыбки» находят модель из банка (`RoundLogic.stem` — грубый стеммер по окончаниям, одинаково для банка и слова игрока). Не ловит «собачка», «кошка» — для них генерация на лету
- [x] **Проверено в Studio**: `GenerateMeshAsync` не годится (меш грузится только на клиенте и не реплицируется) — ModelCache переведён на `GenerateModelAsync(inputs, {PredefinedSchema="Body1"})`: работает на сервере, ~18 с, понимает русское слово, модель видна всем
- [x] Генерация раунда идёт параллельно с паузой (раньше — после паузы, +1–4 с ожидания). Раньше нельзя: слово победителя известно только после раунда
- [x] Цель collect: собрать 3 звезды (звёзд на всех не хватает)
- [x] Цели: `hide` (навесы, их вдвое меньше, чем игроков; в конце луч вверх — кто без крыши, вылетает) и `push` (E / кнопка «Толк!» → сервер толкает ближайшего VectorForce-ом; кто никого не столкнул — вылетает, если в начале было ≥2 живых). Все 6 целей из дизайна. `hide` проверен в Studio; `push` — только толчок и соло-режим, вдвоём **не проверен**
- [x] Угрозы: chaser (существо из слова), wind, darkness, gravity — все 7 из дизайна
- [x] Самопроверка: у каждой цели/угрозы из Config есть обработчик, фраза и хотя бы одна честная пара
- [x] Подвохи (`Services/Twists`, шанс 35%): `reverse` (клиент подменяет `moveFunction` ControlModule — проверено: W ведёт назад), `tiny` (персонажи ×0.4), `leader` (охотник гонится только за лидером по победам). ИИ упоминает подвох во фразе, HUD показывает «подвох: …»
- [x] Арена 16×16 плиток (96×96 вместо 60×60); сжатие пола, столбы лавы и частота падающих предметов масштабируются под размер
- [x] Ещё 3 арены: `kitchen`, `candy`, `space` (+ оформлен `school`). Та же сетка плиток (цели/угрозы не трогали), разные плитки, свет и декор; декор без коллизий, чтобы не ловить падающих; крупный реквизит — модели из банка слов. ИИ выбирает арену, `Arena.build(round.arena)`. Проверено в Studio: все 4 построены и сняты, раунд сам выбрал `candy`
- [x] Ловушки разных типов (`Services/Traps`): jump, move (ввод, не скорость), chat, tile (красные плитки вдали от игроков). Все 4 проверены в Studio реальным вводом

## Внешний вид

- [x] VFX (`Services/Vfx` + `client/Vfx`, встроенные текстуры, без загрузок): вылет — дым, искры и кольцо; падение предмета — пыль и кольцо; толчок; подобранная звезда; конфетти выжившим; постоянные — искры и жар лавы, блеск звёзд, маяк зоны, пламя охотника, дым преследователя; плитки при сжатии тают
- [x] Модели для арен: запечено ещё 10 (глобус, автобус, тостер, кастрюля, чайник, пряник, кекс, астронавт, нло, спутник) — расставлены по аренам и заодно стали словами банка (теперь 40)
- [x] Атмосфера арен: своя дымка на арену, Bloom (неон светится), лёгкая цветокоррекция; темнота сгущает дымку
